# Asignación de preguntas — Equipo Merxirve

## Regla

Cada pregunta del seminario corresponde a **una issue fija** en GitHub (#1–#6). El responsable es quien figure como **Assignee** en esa issue.

- Etiquetas: `pregunta` y `pregunta-XX`.
- Las issues se crean al publicar el repositorio (una por pregunta), **sin assignee**.
- **Cada integrante se asigna a sí mismo** en GitHub cuando tome una pregunta (campo **Assignees** en la issue). Si dos personas quieren la misma pregunta, acuerden en el equipo antes de asignarse.

## Pasos para el equipo

1. Ir a [Issues](https://github.com/Anthonycg2003/seminario-IS-Arquitecturas-de-Software/issues) y abrir la issue de tu pregunta (#1–#6).
2. Pulsar **Assignees** y asignarte (o al compañero acordado).
3. Crear una rama, editar el `.tex` indicado en la issue y abrir un **PR a `main`** (no push directo a `main`). Enlazar el PR a la issue si aplica; esperar CI en verde antes del merge.
4. Cerrar la issue cuando el PR esté mergeado y la sección revisada.
5. Antes del PDF final, copiar en [`latex/sections/00-portada.tex`](../latex/sections/00-portada.tex) el nombre del assignee y el número de issue (debe coincidir con GitHub).
