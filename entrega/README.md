# Entrega

El PDF final se genera al compilar desde `latex/` (no se sube a GitHub):

- **Nombre requerido:** `SemArq1_Merxirve.pdf`
- **Local:** `make pdf`, o `scripts/build-pdf.ps1` (Windows) / `scripts/build-pdf.sh` (Linux, macOS).
- **En GitHub:** tras merge a `main`, descargar el artefacto `SemArq1-pdf` del workflow *Compilar LaTeX* en Actions.
- Debe coincidir con el archivo subido a Telegram (Evaluaciones).

Hasta la primera compilación, este directorio puede estar vacío salvo este archivo.
